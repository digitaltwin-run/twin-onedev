# twin-onedev — Digital Twin OneDev Git Server Simulator

`twin-onedev` to autonomiczny komponent Digital Twin symulujący serwer git OneDev oraz lustrzane kopie repozytoriów platformy Subactor.

## Funkcje
- Weryfikacja referencji repozytoriów `onedev://subactor/*`.
- Symulacja webhooków push i git fetch/mirror.
